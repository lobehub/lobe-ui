## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/EmptyState) empty state: a dashed 14px frame, the icon in a round well (an inbox by default), a 14px title, a muted hint and a primary action. Pass `action={{ label, onClick }}` to get the playground's button; any other node renders as is.

## APIs

### Empty

<Api name="Empty" migrationKey="heading:%5B%22Empty%22%5D:0" />

`Empty` renders a native `<div>`. All standard div HTML attributes including `onClick`, `aria-*`, `data-*`, `style`, and `ref` are forwarded to the root element.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Empty`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Empty.css';
```
