title: AnimatedNumber

## Basic

The first render shows the value as is; later changes ease to the new value. A change that lands mid-flight continues from the number on screen. `formatter` receives the in-flight value, which is fractional while it moves.

## APIs

<Api name="AnimatedNumber" />

`AnimatedNumber` renders a text node with no wrapper, so it has no class names or styles of its own. With reduced motion preferred, the value updates without the transition.
