## Usage

Each option is a toggle chip; `value` (or `defaultValue`) holds the picked values in the options' order, and `onChange` receives the next list. While something is picked, the label row shows "N selected" (`showCount={false}` hides it). The default variant uses lobe-ui chips.

<Demo of={Basic} />

## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/ChipSelect) chips: 28px pills with 12.5px type, and an accent wash, hairline and check mark when picked. Colours stay the lobe-ui theme's (the accent is the primary colour).

The `chipSelect.selected` text (with `{count}`) comes from `@lobehub/ui/i18n`; `texts` overrides it.

## Styles

`@lobehub/ui/style.css` already includes the styles of `ChipSelect`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/ChipSelect.css';
```
