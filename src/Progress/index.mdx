## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/Progress) progress bar: a label and percent row over a 6px bar, with an optional `caption` under it. `status` picks the tone (`normal` accent, `success` positive, `exception` negative, `active` info) and `strokeColor` overrides it.

<Demo of={DemoA2ui} layout="bare" />

With `type="circle"` it is the playground's [radial progress](https://a2ui.open.bot/components/RadialProgress) card: a 76px ring with the value inside, and `label` and `caption` (by default "68 of 100") beside it.

## APIs

<Api name="Progress" from=".." />

`Progress` renders a native `<div>`. All standard div HTML attributes including `className`, `style`, `data-*`, and `ref` are forwarded to the root element.

### Variants

`type="line"` (default) supports three `variant`s: `line` (a label and value row above a thin track), `segments` (independent cells, count set by `segments`), and `inset` (a meter: a filled pill and a remaining pill split by a small gap). `type="circle"` renders an SVG ring instead.

### Status

`status` accepts `normal`, `active`, `success`, or `exception`. `success` and `exception` replace the info text with a check or cross icon; `active` adds a shimmer animation to the `line` and `inset` bars.

### Migrating from antd Progress

```tsx | pure
import { Progress } from '@lobehub/ui';

<Progress percent={62} status="active" />;
```

`steps`, `strokeLinecap="square"`, `trailColor`, and gradient `strokeColor` are not supported; use `variant="segments"` for step-like semantics.

antd's `size="default"` becomes `size="middle"`.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Progress`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Progress.css';
```
