## Basic

`picker` switches between `date`, `week`, `month`, `quarter` and `year`; each has antd's default format (`YYYY-MM-DD`, `gggg-wo`, `YYYY-MM`, `YYYY-[Q]Q`, `YYYY`) and placeholder. The year panel shows a decade (10 years plus the neighbours at either end), and its header drills up to a century of decades. `onChange` receives `(date: Dayjs | null, dateString: string | null)`; clearing passes `null` for both. The input is typeable — a date in `format` is parsed as you type and committed on Enter or blur.

## Date format

`format` takes the same `FormatType` as antd:

- a dayjs format string (`'YYYY/MM/DD'`) — used to show the value, build the `dateString` and parse what is typed;
- a function `(value: Dayjs) => string` — display only; typed text can no longer be parsed;
- an array of strings / functions — the first one is used to show the value and build `dateString`, and typed text is tried against every string format in turn (`13/10/26` and `13-10-2026` both match `['DD/MM/YYYY', 'DD/MM/YY', 'DD-MM-YYYY', 'DD-MM-YY']`). Put a function first and strings after it to show custom text while still accepting typed dates.

Defaults follow antd: `YYYY-MM-DD` (`YYYY-MM-DD HH:mm:ss` with `showTime`), `gggg-wo`, `YYYY-MM`, `YYYY-[Q]Q` and `YYYY` per `picker`.

Typed text is parsed in strict mode through dayjs's `customParseFormat` plugin, which the picker registers itself. To build a `Dayjs` from a string in a custom format in your own code (`dayjs('2015/01/01', 'YYYY/MM/DD')`), extend dayjs with it once, as in antd:

```ts
import dayjs from 'dayjs';
import customParseFormat from 'dayjs/plugin/customParseFormat';

dayjs.extend(customParseFormat);
```

## Mask input

`format={{ format, type: 'mask' }}` turns the input into a masked field, as in antd 5.14+: on focus the empty input shows the format as a template, digits fill one segment at a time and move on, ArrowUp / ArrowDown step the focused segment, ArrowLeft / ArrowRight move between segments, Backspace resets one, and pasting a full date in the format fills it. Enter commits the date. Works on the range picker too.

## Customized cell rendering

`cellRender(current, info)` renders every cell of every panel. `info` carries `originNode` (the default cell), `today`, `type` (`date` / `week` / `month` / `quarter` / `year` / `decade`), `locale`, `prefixCls` and, on `DateRangePicker`, `range` (`'start'` / `'end'`). The deprecated `dateRender(current, today)` and `monthCellRender(current, locale)` still work for the date and month panels when `cellRender` is not set.

## Keyboard on month, quarter and year panels

While the popup shows a month, quarter, year or decade panel, ←/→ move one tile, ↑/↓ one row, PageUp/PageDown one page (a year, or a decade / century), Home/End jump to the first / last tile of the page, and Enter picks the highlighted tile — the same as clicking it. Values are `Dayjs` objects, exactly as in antd. `minDate` / `maxDate` replace `min` / `max`, which remain as deprecated aliases; `footer` is a deprecated alias of `renderExtraFooter`, and `onSelect` of `onCalendarChange`. Week start and week / month names follow the active dayjs locale.

The popup is rendered with `@rc-component/trigger`. Inside a base-ui floating layer (Popover, DropdownMenu) or a dialog it mounts in that layer, so picking a date never counts as an outside click for the host; elsewhere it mounts on `document.body` like antd, carrying the theme's CSS-variable scope so light / dark tokens still apply. It takes its z-index from the shared base-ui layer counter. Pass `getPopupContainer` to mount it elsewhere.

### Keyboard

Input keys match antd DatePicker: type a date and press Enter to commit it, Escape closes the popup, Tab moves on (and between the two inputs of a range). The input stays the single keyboard target; the calendar cells are never focused.

On top of antd, the month, quarter, year and decade panels take arrow keys, PageUp/PageDown, Home/End and Enter while the popup is open (see the demo above); the highlighted tile is outlined and the page follows it. On those panels the arrow keys therefore no longer move the text caret while the popup is open. The date and week panels keep antd's behaviour: no arrow-key navigation, arrow keys move the caret.

### Migrating from the previous lobe DatePicker

- `Date` values → `Dayjs`: wrap with `dayjs(date)` when passing a value and call `.toDate()` in `onChange`. `onChange` now also receives the formatted string.
- `mode="month"` / `mode="year"` → `picker="month"` / `picker="year"`. `mode` now means the controlled panel, as in antd.
- `min` / `max` → `minDate` / `maxDate` (`Dayjs`); `disabledDate(date: Date)` → `disabledDate(current: Dayjs, info)`.
- `DateRangePicker` clears to `null` instead of `[null, null]`.
- The trigger is now an `<input>` instead of a `<button>`; the panel no longer moves focus into the day grid.
