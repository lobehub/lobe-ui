## Basic

`picker` switches between `date`, `month` and `year`. `onChange` receives `(date: Dayjs | null, dateString: string | null)`; clearing passes `null` for both. The input is typeable — a date in `format` is parsed as you type and committed on Enter or blur.

## Range

`DateRangePicker` takes and emits a `[Dayjs, Dayjs]` pair (or `null` once cleared), with `dateStrings` as the second argument.

## Controlled panels

`mode` controls the visible panel the antd way: the panel only changes when you update `mode` from `onPanelChange`. Both pickers start on a higher panel and drill down as `mode` follows `onPanelChange`; the range picker takes a `[start, end]` mode tuple.

Values are `Dayjs` objects, exactly as in antd. `minDate` / `maxDate` replace `min` / `max`, which remain as deprecated aliases; `footer` is a deprecated alias of `renderExtraFooter`, and `onSelect` of `onCalendarChange`. Week start and week / month names follow the active dayjs locale.

The popup is rendered with `@rc-component/trigger`. Inside a base-ui floating layer (Popover, DropdownMenu) or a dialog it mounts in that layer, so picking a date never counts as an outside click for the host; elsewhere it mounts on `document.body` like antd, carrying the theme's CSS-variable scope so light / dark tokens still apply. It takes its z-index from the shared base-ui layer counter. Pass `getPopupContainer` to mount it elsewhere.

### Keyboard

Keyboard behaviour matches antd DatePicker: type a date and press Enter to commit it, Escape closes the popup, Tab moves on (and between the two inputs of a range). Like antd, the calendar cells are not focusable and there is no arrow-key navigation inside the panel — the input stays the single keyboard target, so arrow keys keep moving the text caret.

### Migrating from the previous lobe DatePicker

- `Date` values → `Dayjs`: wrap with `dayjs(date)` when passing a value and call `.toDate()` in `onChange`. `onChange` now also receives the formatted string.
- `mode="month"` / `mode="year"` → `picker="month"` / `picker="year"`. `mode` now means the controlled panel, as in antd.
- `min` / `max` → `minDate` / `maxDate` (`Dayjs`); `disabledDate(date: Date)` → `disabledDate(current: Dayjs, info)`.
- `DateRangePicker` clears to `null` instead of `[null, null]`.
- The trigger is now an `<input>` instead of a `<button>`; the panel no longer moves focus into the day grid.
