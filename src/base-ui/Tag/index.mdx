## APIs

<Api name="Tag" from=".." />

`Tag` renders a native `<span>`. All standard span HTML attributes including `onClick`, `aria-*`, `data-*`, `style`, and `ref` are forwarded to the root element.

### Color

`color` accepts one of the 13 preset names (`red`, `volcano`, `orange`, `gold`, `yellow`, `lime`, `green`, `cyan`, `blue`, `geekblue`, `purple`, `magenta`, `gray`), the system colors (`success`, `warning`, `error`, `info`, `processing`), or any raw hex string. Preset and system colors resolve through theme tokens, so they follow light/dark themes automatically.

### Variants

- `filled` (default): tinted background with a subtle border.
- `outlined`: transparent background with a colored border.
- `borderless`: transparent background without a border.
- `solid`: solid background with an auto-computed readable text color.

### Migrating from antd Tag

The core migration is an import replacement:

```tsx | pure
import { Tag } from '@lobehub/ui/base-ui';

<Tag color="success" variant="solid">
  online
</Tag>;
```

`closable` renders a built-in close button that stops propagation, invokes `onClose`, and removes the tag. Use `closeIcon` to replace the default close glyph. `classNames.root` / `styles.root` and `classNames.closeIcon` / `styles.closeIcon` provide slot-level overrides for the root span and the close button.
