## APIs

### Skeleton

<Api name="Skeleton" from=".." />

`Skeleton` renders a plain `<div>`; every standard div attribute is forwarded to it. It is the only primitive — a card, a button, an image or a chart placeholder is this block with a `width`, `height` and `radius`.

### Skeleton.Text

Lines sized from the font metrics, so a placeholder occupies the same box the real text will.

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| rows | Number of lines | `number` | `1` |
| fontSize | Font size the lines stand in for | `number` | `fontSize` |
| lineHeight | Line height the lines stand in for | `number` | `1.6` |
| width | Width of all lines, or one width per line | `number \| string \| (number \| string)[]` | `'100%'`, last line `'66%'` when `rows > 1` |
| gap | Explicit gap between lines, replacing half-leading | `number` | - |
| animated | Pulse while loading | `boolean` | `true` |

### Skeleton.Avatar

| Property | Description         | Type                   | Default    |
| -------- | ------------------- | ---------------------- | ---------- |
| size     | Width and height    | `number \| string`     | `40`       |
| shape    | Avatar shape        | `'circle' \| 'square'` | `'square'` |
| animated | Pulse while loading | `boolean`              | `true`     |

## Migration

The antd-shaped API is gone. `active` is now `animated` and defaults to `true`.

| Before | After |
| --- | --- |
| `<Skeleton.Block height={16} width="60%" />` | `<Skeleton height={16} width="60%" />` |
| `<Skeleton.Button active style={{ height: 16 }} />` | `<Skeleton height={16} />` |
| `<Skeleton.Button block size="small" />` | `<Skeleton height={28} />` |
| `<Skeleton active paragraph={{ rows: 3 }} title={false} />` | `<Skeleton.Text rows={3} />` |
| `<Skeleton.Paragraph rows={3} fontSize={14} />` | `<Skeleton.Text rows={3} fontSize={14} />` |
| `<Skeleton.Title fontSize={20} width="30%" />` | `<Skeleton.Text fontSize={20} width="30%" />` |
| `<Skeleton.Tags count={2} />` | two `<Skeleton />` in a `<Flexbox horizontal />` |
