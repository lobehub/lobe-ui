## Usage

Put two to four short follow-ups at the end of an answer. A string item is both the pill text and the message; an object can send a longer `message` than its `label`. `onFollowUp` receives the message, the item and its index. The default variant uses lobe-ui pills.

<Demo of={Basic} layout="bare" />

## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/FollowUp) follow-ups (the CopilotKit standard `FollowUp`): a muted caption and bordered pills whose type follows the surrounding font size. Colours stay the lobe-ui theme's.
