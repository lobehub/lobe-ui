## A2UI

`variant="a2ui"` takes the look of the A2UI playground's standard [RadioGroup](https://a2ui.open.bot/components/RadioGroup) (CopilotKit Gen UI 2.0): a muted `label` above the options, 20px radios that turn into a primary ring when chosen, and type that follows the surrounding font size. Options can carry a `description`. `Radio` takes the same `variant` on its own.

<Demo of={DemoA2ui} layout="bare" />

`optionVariant` draws each option as a plain `list` row (the default), a bordered `pills` pill or a bordered `cards` card; the chosen pill or card takes a primary border. Options flow in a row unless `horizontal={false}`.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Radio`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Radio.css';
```
