## Basic

Mark each row with `data-glide-row`. The highlight fades in on the first row it meets, then slides to the next one; rows need no hover background of their own.

<Demo of={DemoIndex} layout="bare" />

## Horizontal

The layer tracks position and size on both axes, so the same wrapper works for a row of tabs. Shape it through `styles.highlight` or the `--lobe-glide-highlight-radius` and `--lobe-glide-highlight-color` variables.

<Demo of={DemoHorizontal} layout="bare" />

## APIs

<Api name="GlideHighlight" />

`useGlideHighlight` returns the same tracking for a container you render yourself, such as a `ul`. Spread `containerProps` on the container, attach `containerRef`, and apply `highlightStyle` to an absolutely positioned layer.

## Styles

`@lobehub/ui/style.css` already includes the styles of `GlideHighlight`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/GlideHighlight.css';
```
