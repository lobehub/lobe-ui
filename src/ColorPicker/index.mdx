## Alpha, formats and empty values

`defaultFormat` picks the channel inputs the panel opens with; the format select in the panel switches between HEX, RGB and HSL. An empty `value` renders as “No colour”.

<Demo of={DemoAlpha} layout="bare" />

## APIs

<Api name="ColorPicker" from=".." />

Values are lowercase hex strings; with `alpha` they are always 8 digits. `onChange` fires while dragging, `onChangeComplete` when the pointer is released or an input commits, so write to a store in `onChangeComplete`. Pass a single element as `children` to use your own trigger.

The panel keeps the colour it opened with in the compare swatch: click its top half to restore it. Committed colours collect under a Recent tab next to Presets for the rest of the session; set `recent={false}` to hide them.

### Migrating from antd ColorPicker

- `Color` objects → hex strings; `onChangeComplete={(c) => c.toHexString()}` → `onChangeComplete={(hex) => …}`.
- `disabledAlpha` is the default; set `alpha` to enable it.
- `presets={[{ label, colors }]}` → `presets={colors}`.
- `showText` → `trigger="field"` (`showText` still works).
- `format` / `defaultFormat` → `defaultFormat` only; values are always hex, the format only changes the panel inputs.
- Gradients are not supported.
