## Usage

`MathFormula` typesets `value` with KaTeX, the renderer lobe-ui's `Markdown` uses. `block` centres the formula on its own line; without it the formula sits inline in the text. An invalid formula shows its source in the error colour instead of throwing, and commands that make links or raw HTML stay off. The default variant matches `Markdown` math: body size, and a wide block scrolls sideways.

## A2UI

`variant="a2ui"` takes the look of the CopilotKit Gen UI standard `Math` used by the [A2UI playground](https://a2ui.open.bot/components/Math): a 16px base and KaTeX's own display spacing. Colours stay the lobe-ui theme's.

## APIs

<Api name="MathFormula" />

KaTeX needs its stylesheet. `ConfigProvider` loads `katex.min.css` with the default web fonts; without it, import `katex/dist/katex.min.css` yourself. The component is named `MathFormula` so that importing it does not shadow the global `Math`.

## Styles

`@lobehub/ui/style.css` already includes the styles of `MathFormula`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/MathFormula.css';
```
