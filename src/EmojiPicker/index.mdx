## Agent Avatar

`createAgentAvatarTab` adds an [AgentAvatar](/components/agent-avatar) panel as the first tab. The value is a string such as `agent-avatar:lobot:geekblue`, which the trigger draws as the avatar. Read it back with `parseAgentAvatar`.

<Demo of={DemoAgentAvatar} layout="center" />

Set `allowEmoji={false}` to offer only the agent avatars. With a single tab left, the tab bar is hidden.

## APIs

<Api name="EmojiPicker" migrationKey="unheaded:0" />

### EmojiPickerCustomEmoji

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| id | Unique identifier for the emoji set | `string` | - |
| name | Name of the emoji set | `string` | - |
| emojis | Array of emoji definitions | `Array<{ id: string; name: string; keywords?: string[]; skins: Array<{ src: string }> }>` | - |

### EmojiPickerCustomTab

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| value | Unique identifier for the tab | `string` | - |
| label | Label to display for the tab | `ReactNode` | - |
| placement | Where the tab sits; a `start` tab comes first and is the one the picker opens on | `'start' \| 'end'` | `'end'` |
| render | Render function for the tab content | `(handleAvatarChange: (avatar: string, options?: { keepOpen?: boolean }) => void, avatar: string) => ReactNode` | - |
| renderValue | Draws a value this tab produced in the trigger; return `undefined` for other values | `(avatar: string, size: number) => ReactNode` | - |

## Styles

`@lobehub/ui/style.css` already includes the styles of `EmojiPicker`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/EmojiPicker.css';
```
