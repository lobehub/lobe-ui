## Usage

The trigger shows the picked option's label (or `placeholder`). It opens a search field over the options; typing filters them by label, value and `keywords`, arrow keys move the highlight and Enter picks it. `onChange` receives the value and the option. The default variant is a lobe-ui select-like trigger and popup.

<Demo of={Basic} />

## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/Combobox) combobox: a 34px outline trigger with an up-down chevron, and a command list (a rounded search field, 13px items, a check on the picked one) in a 10px popover as wide as the trigger. Colours stay the lobe-ui theme's.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Combobox`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Combobox.css';
```
