## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/Switch) switch: a 32 × 18px track with a 16px thumb. With a `label` (and an optional `description`) it sits on the right of a well row that holds them, and the label is the switch's `<label>`. Colours stay the lobe-ui theme's.

<Demo of={DemoA2ui} />

## Styles

`@lobehub/ui/style.css` already includes the styles of `Switch`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Switch.css';
```
