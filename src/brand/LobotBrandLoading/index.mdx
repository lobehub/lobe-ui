## Example

The mark keeps the brand's black body and white outline on any background, and the animation is CSS only, so it runs before the app hydrates. That makes it the loader for a splash screen. For a quiet placeholder inside a page, use [LobotBrandLoading3d](/components/brand/lobot-brand-loading3d).

<Demo of={DemoIndex} />

## Sizes

`size` matches `LobotMono` at the same value, so the loader can hand over to the static logo without a jump. The outline of a bubble passes slightly above the box at the top of its orbit, so leave a little room there.

## Styles

`@lobehub/ui/style.css` already includes the styles of `LobotBrandLoading`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/brand/LobotBrandLoading.css';
```
