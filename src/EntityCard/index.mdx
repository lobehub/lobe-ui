## Usage

The subtitle and badge sit above the title, then the rating, a description clamped to three lines, a meta line such as a price, and up to three actions. `layout="horizontal"` puts a square image on the left. With `href` or `onClick` the whole card is a link-like control; actions stop the click from reaching it. The default variant is a lobe-ui card with lobe-ui `Tag` and `Button`.

## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/EntityCard) entity card (the CopilotKit standard `EntityCard`): a 16px card, compact type that follows the surrounding font size, a soft badge pill, text stars and pill buttons. Colours stay the lobe-ui theme's.

## APIs

<Api name="EntityCard" />

An action's `variant` is `solid` (primary), `soft` (filled), `outline` or `ghost`; without one, an action with `href` (or any action when the card has `onAction`) is `outline`, else `ghost`. An action runs its own `onClick`, else opens its `href` in a new tab, else calls the card's `onAction`. `badge` takes `{ label, color }` (`default`, `secondary`, `success`, `danger`, `warning`, `info`, `discovery`) or any node.

## Styles

`@lobehub/ui/style.css` already includes the styles of `EntityCard`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/EntityCard.css';
```
