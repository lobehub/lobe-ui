## Usage

Pass a stable `seed`, or a `name` that doubles as the accessible label. The same seed always draws the same avatar, with no randomness and no stored image.

```tsx
import { AgentAvatar } from '@lobehub/ui';

<AgentAvatar animated name="Writer" size={48} state="working" />;
```

<Demo of={DemoIndex} layout="bare" />

Without a `name` or `aria-label` the avatar is decorative and hidden from assistive technology. A seeded lean of -3° to 3° keeps a row of avatars from looking rigid; set `tilt={false}` for a straight pose.

## Shapes

Every shape is one soft outline with a dominant face, so it stays recognizable at sidebar size. `lobot` is the logo itself. `shape` overrides the one derived from the seed.

<Demo of={DemoShapes} layout="bare" />

## Colors

`color` overrides the derived color. Palette keys resolve to theme color tokens and adapt to dark mode, and any other string is used as a CSS color. The eyes stay white and near black in every color.

<Demo of={DemoColors} layout="bare" />

## States

`state` tells what the agent is doing, on the avatar itself: `idle` looks around and blinks, `working` scans across its work, `waiting` lowers its lids, `thinking` looks up with small thought bubbles, `blocked` goes wide-eyed with an error badge, and `done` closes its eyes in a smile and gives two small hops. Every state stays inside the avatar's box, so it never needs extra room in a layout.

<Demo of={DemoStates} layout="bare" />

Motion is off by default. `animated` plays it, and `prefers-reduced-motion: reduce` always falls back to the still pose. Animated avatars share one frame loop, pause outside the viewport and draw at 30 fps below 128px.

## Follow pointer

With `animated`, `followPointer` turns the eyes and body toward the mouse, pen or finger.

## In EmojiPicker

`createAgentAvatarTab` adds the panel to `EmojiPicker` as a custom tab. The value is a plain string such as `agent-avatar:rocket:volcano`, so it fits an existing avatar field. `parseAgentAvatar` reads it back into props for `AgentAvatar`, and `stringifyAgentAvatar` writes it.

## API

<Api name="AgentAvatar" />

### AgentAvatarPicker

<Api name="AgentAvatarPicker" from="." />

`AGENT_AVATAR_SHAPES`, `AGENT_AVATAR_COLORS` and `AGENT_AVATAR_STATES` list the accepted values, and `getAgentAvatarTraits(seed)` returns the derived `shape`, `color`, `tilt` and animation `phase` without rendering.

## Styles

`@lobehub/ui/style.css` already includes the styles of `AgentAvatar`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/AgentAvatar.css';
```
