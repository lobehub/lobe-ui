## A2UI

`variant="a2ui"` takes the look of the A2UI playground's standard [Slider](https://a2ui.open.bot/components/Slider) (CopilotKit Gen UI 2.0): a 24px pill track with a 20px thumb and no filled range, under a row with the `label` and the current value (shown when there is a `label` or a `unit`, e.g. `%`). Type follows the surrounding font size; colours stay the lobe-ui theme's.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Slider`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Slider.css';
```
