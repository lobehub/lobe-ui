## Usage

Each day shows its weekday (or `label`, such as "Today"), day number and month, then its events as rows with a tone bar, the time, the title and an optional speaker, description and location. A day without events reads "Nothing scheduled". The default variant is a plain lobe-ui card with body-size type.

<Demo of={Basic} layout="bare" />

## A2UI

`variant="a2ui"` takes the layout of the [A2UI playground](https://a2ui.open.bot/components/Agenda) agenda: a 14px card with a soft shadow, compact 12.5 to 13px type and hairline rules. Colours stay the lobe-ui theme's in both variants.

## APIs

<Api name="Agenda" />

`date` is a `YYYY-MM-DD` string (read as a local date) or anything `Date` can parse. Weekday and month names follow `locale`, then the `ConfigProvider` locale. `tone` colours the event's bar: `accent` (default, the primary colour), `positive`, `negative`, `warning`, `info` or `default`; lobe-ui colour names such as `success` or `error` map to the same tones. The `agenda.allDay` and `agenda.empty` texts come from `@lobehub/ui/i18n`; `texts` overrides them.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Agenda`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Agenda.css';
```
