## Basic

Pass a `url` or a `host`. An invalid URL, an empty one, or an icon that fails to load falls back to a globe; `fallback` replaces it.

<Demo of={DemoIndex} layout="bare" />

## Icon source

Icons come from the DuckDuckGo icon service by default, so the visitor's browser requests it for every host shown. Pass `getIconUrl` to use a proxy or another provider, or `src` when you already have the icon URL.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Favicon`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Favicon.css';
```
