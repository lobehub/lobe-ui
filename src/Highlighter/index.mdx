## A2UI

`variant="a2ui"` takes the look of the [A2UI playground](https://a2ui.open.bot/components/CodeBlock) code block: a card with three dots, the `fileName` (or the language) and a Copy button over the code, highlighted with the same lobe-ui syntax theme as the other variants, so it follows light and dark; pass `theme` to use another highlighter theme inside the same frame.

### SyntaxHighlighter

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| children | Code content to highlight | `string` | - |
| language | Programming language for syntax highlighting | `string` | - |
| theme | Syntax highlighting theme | `'lobe-theme' \| BundledHighlighterTheme` | - |
| variant | Visual style variant | `'filled' \| 'outlined' \| 'borderless' \| 'a2ui'` | - |

## Styles

`@lobehub/ui/style.css` already includes the styles of `Highlighter`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Highlighter.css';
```
