## Usage

`WeatherCard` renders the values it is given and fetches nothing. The hero shows the location, the temperature, the condition and the high and low, with the condition icon on the right. Feels-like, humidity and wind sit in three small panels below; `hourly` adds a scrolling strip with the first hour highlighted and the chance of rain under each hour, and `daily` adds forecast rows whose bars place each day's low-to-high range on the week's scale. The default variant is a plain lobe-ui card with body-size type.

## A2UI

`variant="a2ui"` takes the layout of the [A2UI playground](https://a2ui.open.bot/components/WeatherCard) weather card: a 14px card with a soft glow in the condition's colour, compact type and hairline panels. Colours stay the lobe-ui theme's in both variants.

## APIs

<Api name="WeatherCard" />

`icon` is one of `sun`, `cloud-sun`, `cloud`, `fog`, `drizzle`, `rain`, `snow` or `storm` (lucide icons); free text such as "Light rain" or a missing `icon` is matched from the words in `condition`. `unit` sets the temperature unit and the wind unit (`C`: km/h, `F`: mph). The `weatherCard.*` texts come from `@lobehub/ui/i18n`; `texts` overrides them.

## Styles

`@lobehub/ui/style.css` already includes the styles of `WeatherCard`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/WeatherCard.css';
```
