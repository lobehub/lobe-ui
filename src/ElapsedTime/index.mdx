## Basic

Pass `startTime` so a remount does not restart the clock, and `endTime` once the work is done to show the final duration. `format="clock"` suits longer runs.

<Demo of={DemoIndex} layout="bare" />

## APIs

<Api name="ElapsedTime" />

`useElapsed(startTime, { enabled, interval })` returns the elapsed milliseconds for a label you render yourself, and `formatElapsed(milliseconds, format)` formats them the same way the component does.

## Styles

`@lobehub/ui/style.css` already includes the styles of `ElapsedTime`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/ElapsedTime.css';
```
