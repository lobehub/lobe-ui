## Default

With both `agent` and `human` panels the card shows an "I'm an Agent / I'm a Human" toggle. The logo row defaults to `DEFAULT_SKILL_AGENTS`, built from `@lobehub/icons`.

<Demo of={DemoIndex} layout="bare" />

## Custom agents and footer

Pass `agents` to change the logo row, or an empty array to hide it. Omit `human` to show only the prompt.
