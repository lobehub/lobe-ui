## Routing

Actions render plain anchors. Pass `renderLink` to use your router's link component:

```tsx
import { Link } from 'react-router';

<LandingHero
  renderLink={({ external, href, ...props }) =>
    external ? (
      <a href={href} rel="noreferrer" target="_blank" {...props} />
    ) : (
      <Link to={href} {...props} />
    )
  }
  title="LobeHub"
/>;
```

Put a `LogoMarquee` in `children` to show it across the full width under the hero.
