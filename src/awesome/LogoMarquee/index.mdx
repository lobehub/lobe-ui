## Default

Items accept an icon component such as `OpenAI` from `@lobehub/icons`, or any React node. The strip pauses on hover and stops when reduced motion is preferred.

## Styles

`@lobehub/ui/style.css` already includes the styles of `LogoMarquee`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/awesome/LogoMarquee.css';
```
