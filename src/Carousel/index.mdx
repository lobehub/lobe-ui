## A2UI

`variant="a2ui"` takes the look of the [A2UI standard carousel](https://a2ui.open.bot/components/Carousel): slides at their own width in a row that scrolls sideways and snaps to each slide's start (`snap`), 8px apart (`slideGap`), with 32px round arrows that hide at either end and no dots. Each child is one slide laid out as a 16px-gap column, so a fragment of a title and a caption becomes one slide. `index` / `onIndexChange` and the `ref` methods follow the slide nearest the start. Colours are the lobe-ui theme's.

## APIs

<Api name="Carousel" from=".." />

Each child is a slide. `autoplay` takes `true` (5s) or an interval in ms and pauses while hovered unless `pauseOnHover={false}`. `adaptiveHeight` animates the viewport to the active slide's height. The ref exposes `goTo(index)`, `next()` and `prev()`. Touch swipes change slides; inactive slides are `inert`.

### Migrating from antd Carousel

- `beforeChange` / `afterChange` → `onIndexChange(index)`; controlled `index` is supported.
- `autoplaySpeed` → `autoplay={ms}`; `dots={false}` and `ref.goTo` keep working.
- `effect="fade"`, `vertical`, `dotPosition`, `draggable` and other slick settings are not supported.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Carousel`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Carousel.css';
```
