---
title: Surface
description: Surface is an elevated card for dashboard panels. Bare, it is a plain frame. With a title, description or extra it gets a header, a padded body whose trailing table meets the card edges, an optional chart slot, and first-load / refresh states. Links go through `renderLink` or `SurfaceLinkProvider`, so the app router stays in the app.
category: Layout
order: 2
