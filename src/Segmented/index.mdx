## Custom semantic dom styling

`classNames` and `styles` target each part: `root` (the toggle group; `list` is an alias), `indicator` (the sliding active background), `item` (each option button), `itemIcon` and `itemLabel`. For a compact control on mobile, set `height` / `paddingInline` on `item`; the indicator follows the measured item size.

<Demo of={DemoSemantic} />

## A2UI

`variant="a2ui"` takes the look of the A2UI playground's standard [SegmentedControl](https://a2ui.open.bot/components/SegmentedControl) (CopilotKit Gen UI 2.0): a pill well of 32px segments in the surrounding font size, where the chosen segment is a raised surface, under an optional `label` (which only applies to this variant). `block` stretches the segments; `size`, `glass`, `shadow` and `vertical` do not apply. Colours stay the lobe-ui theme's.

### SegmentedOption

| Property | Description                  | Type        | Default |
| -------- | ---------------------------- | ----------- | ------- |
| value    | Unique value                 | `string`    | -       |
| label    | Option label                 | `ReactNode` | -       |
| icon     | Leading icon                 | `ReactNode` | -       |
| disabled | Whether the item is disabled | `boolean`   | `false` |
| title    | Native title attribute       | `string`    | -       |

`options` also accepts an array of plain strings as shorthand: `['Light', 'Dark']` is equivalent to `[{ value: 'Light', label: 'Light' }, ...]`.

## Styles

`@lobehub/ui/style.css` already includes the styles of `Segmented`. To load only the components you use, import this file instead of `style.css`:

```tsx | pure
import '@lobehub/ui/css/Segmented.css';
```
