Lobe UI's theme is a set of CSS variables (`--lobe-*`) in `@lobehub/ui/theme.css`, switched by `data-theme`, `data-primary-color` and `data-neutral-color` on `<html>` or a `ThemeScope`. This page lists the tokens the components actually read, grouped by role. Every swatch is split: the left half renders in the light theme and the right half in the dark theme, whichever theme the site is in. Values are live and follow the primary and neutral colors picked in the site theme switcher.

```tsx | pure
import { createStaticStyles, cssVar, useTheme } from '@lobehub/ui';

const styles = createStaticStyles(({ css }) => ({
  card: css`
    border: 1px solid ${cssVar.colorBorderSecondary};
    border-radius: ${cssVar.borderRadiusLG};
    background: ${cssVar.colorBgContainer};
  `,
}));

// Concrete values, for canvas or charts
const { colorText } = useTheme();
```

In plain CSS, use the variable name directly: `var(--lobe-color-bg-container)`. Prefer a role token over a raw scale color, so your UI follows theme changes the same way the components do.

## Status

Error, warning, info and success share one structure: the same nine roles, generated from one tone ladder per theme, so a role reads at a similar weight across the four statuses. Read a token as `color` + status + role, for example `colorWarningBorder` (`base` is plain `colorWarning`). Each cell shows the light and dark value; base and Text add their contrast on `colorBgContainer`.
